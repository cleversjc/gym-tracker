# 训练记录 V1

一个纯前端、手机优先的训练记录 PWA。

## 已预装
- 上肢 A：背部 / 体态优先
- 腿 + 核心：上肢恢复日
- 上肢 B：胸肩背综合

## 主要功能
- 记录重量、每组次数、最后一组 RIR
- 训练前记录背 / 胸 / 手臂 / 腿酸痛程度
- 自动读取同动作上次记录
- 简单渐进提示
- 一键复制 / 分享“发给 ChatGPT 的训练报告”
- 历史记录
- JSON 备份 / 恢复
- CSV 导出
- 本地存储，无账号、无服务器

## 本地预览
在本目录运行：

```bash
python -m http.server 8000
```

浏览器打开 `http://localhost:8000`。

## 手机上安装为 App
PWA 需要通过 HTTP/HTTPS 访问。部署到任意静态托管后：
- iPhone Safari：分享 → 添加到主屏幕
- Android Chrome：菜单 → 安装应用 / 添加到主屏幕

如果只直接打开 `index.html`，训练记录仍可使用，但“安装为 App / 离线缓存”可能受浏览器限制。
